# MoleculeLab — Molecular Universe

A responsive educational chemistry website inspired by the supplied MoleculeLab reference page.

## Features
- Overview dashboard with navigation cards
- Searchable starter molecule library
- 3D molecular structure viewer powered by 3Dmol.js and PubChem
- Side-by-side molecule comparison
- Simple library analytics
- Chemistry learning notes
- Downloadable text report

## Project files
- `index.html` — page structure and sections
- `style.css` — responsive styling
- `app.js` — molecule data and interactive features

## Run locally
1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Run `index.html` with the Live Server extension, or open it in a modern browser.

The 3D visualizer requires an internet connection because it loads 3Dmol.js and structure data from PubChem.

## Deploy with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `app.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

## Notes
This is a fresh implementation based on the visible sections and navigation of the reference website. It is not the original source code of the deployed site. Molecular data is a small educational starter set; verify scientific details against trusted chemistry references before academic or laboratory use.
